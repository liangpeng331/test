# AvaloniaNotepad

A simple cross-platform notepad application built with .NET and Avalonia UI.

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

## Build Instructions

### Windows

Open a command prompt or PowerShell and run the following command:

```
build.bat
```

The application will be published to `bin/Release/net8.0/win-x64/publish/`.

### Linux and macOS

Open a terminal and run the following command:

```
./build.sh
```

The application will be published to:
- **Linux:** `bin/Release/net8.0/linux-x64/publish/`
- **macOS:** `bin/Release/net8.0/osx-x64/publish/`
